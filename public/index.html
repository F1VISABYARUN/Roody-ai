Download Chrome extension ↗
  1. 01
    Install the orb

    Extract the ZIP. In chrome://extensions, enable Developer mode → Load unpacked → select the folder with manifest.json.

  2. 02
    Connect your demo

    In orb Settings, enter this server address and your guest code, then Save demo access.

  3. 03
    Say hello

    Press Talk and allow your microphone. Voice costs 30 credits for up to 3 minutes. See my screen lets you choose a work window. Pause stops voice and sharing.
