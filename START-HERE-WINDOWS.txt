ROODY COMPANION 3.2 — VOICE INSIDE THE ORB

INSTALL OR UPDATE IN CHROME
1. Right-click Roody-Companion-3.2.0-Chrome.zip and select Extract All.
2. Open chrome://extensions in Chrome and enable Developer mode.
3. Disable older Roody installs. Click Load unpacked and select the folder
   containing manifest.json. If already using that folder, click Reload.
4. Confirm version 3.2.0 and refresh your work webpage.
5. Click the Roody toolbar icon to open the orb.
No npm command is needed to use the Chrome extension.

DEMO ACCESS
Open the orb Settings gear. Enter the owner's Vercel server address and
invite code, then click Save demo access. A code has 100 credits total:
1 per text reply, or 30 for voice lasting up to 3 minutes. Pausing early does
not refund started voice. A shared code shares its balance. Credits are app
units, not OpenAI dollars. The server must be deployed and configured first.

YOUR OWN KEY
In Settings, expand Use my own OpenAI key instead. Paste your key and click
Save key. Clear the demo server address and save demo access to use your own
key. API billing and Realtime access are required. Do not include the key
in shared files or paste it into chat.

TALK AND WORK
1. Press Talk in the orb and allow microphone access.
2. Roody greets you. Speak naturally; interrupt by speaking.
3. Press See my screen and choose a work/code window in Chrome's picker.
   To compare files, open both side by side in the selected window.
4. Expand Browser following & speaking to enable Follow my browser and
   allow optional website access. Speak up is on initially for brief
   observations when shared context changes and neither of you is speaking.
5. Close the orb panel to work. Voice keeps running across browser page
   changes. Screen sharing stops if its source page navigates; choose the
   screen again from the new page's orb.
6. Pause voice stops the microphone, browser following, and screen sharing.
7. Expand More for personas, language, goals, and tasks. Explain page and
   the message box are available for text chat.

The orb appears inside Chrome, not over native Windows apps. Screen sharing
lets Roody discuss visible desktop code; it cannot read files from disk,
click controls, or apply edits. Browser text is sampled about every 5 seconds,
changed screen images every 12 seconds, with a 30-second spoken check-in
cooldown. Choose a work window to avoid sharing personal information.
