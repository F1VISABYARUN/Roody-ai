ROODY COMPANION 3.1 — TALK WHILE YOU WORK

INSTALL THIS ZIP IN CHROME
1. Right-click Roody-Companion-3.1.0-Chrome.zip and choose Extract All.
2. Open Chrome and type chrome://extensions in the address bar.
3. Turn OFF any older Roody extension. Turn Developer mode ON.
4. Click Load unpacked. Select the extracted folder containing manifest.json.
   If you do not see manifest.json in that folder, open the folder inside it.
5. Confirm the extension version is 3.1.0. Refresh your work webpage.
6. Click the Roody toolbar icon to summon the green orb.

CONNECT YOUR KEY
Click the orb's Settings gear. Paste your OpenAI API key in the OpenAI field
and click Save key. This needs API billing/credits and Realtime model access.
Do not paste your key in a chat. No npm command is needed for this extension.

START THE COMPANION
1. Choose Developer, Grandparent, or Founder and save your current goal.
2. Click Voice, then Start conversation. Allow Chrome's microphone request.
3. Roody greets you and asks a useful question. Speak normally.
4. Enable Follow my browser and allow the optional website-access request.
   Roody reads active work-page text about every five seconds.
5. For VS Code or other desktop code, click Share screen or code window.
   Choose the editor window in Chrome's picker. Open two files side by side.
   Roody receives changed screen images about every twelve seconds.
6. Leave Speak up when something changes ON for brief observations/questions.
   Automatic observations wait while either of you is speaking and have a
   thirty-second cooldown. Ask directly whenever you need help sooner.
7. Click Keep orb talking to minimize the controls and work normally.
   Keep the voice window running. Closing it stops the conversation.
8. Click Voice controls in the page orb to restore the voice window.
   Click Pause voice to stop microphone, page following, and screen capture.

TRY SAYING
"Roody, compare these two files. Point out one likely issue, explain your
reasoning, and ask me one question. Keep guiding me as I work."

IF SILENT
Look at the voice window's status message. Click Enable sound if it appears.
Check that Windows output volume is on and Chrome has microphone permission.
Check the saved API key, API credits, and Realtime model access in Settings.

DEMO SCOPE
The floating orb lives inside Chrome. Sharing a VS Code window lets Roody
discuss its visible pixels; it does not place an orb over other Windows apps
or read files directly from disk. Roody suggests fixes and plans; you apply
edits yourself. Browser following skips personal/sensitive pages. Screen
sharing includes whatever is visible in the surface you choose, so choose
your work window. Page snapshots, sampled images, and voice use your API
account. See PRIVACY.md for details.
