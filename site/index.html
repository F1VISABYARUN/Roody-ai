What Roody does

🧠 Answers & writes code

Ask about the bug, the error, the approach — Roody replies in the chat with real, runnable code in formatted blocks.

👀 Reads the page with you

Code on GitHub, Stack Overflow, docs, editors, PDFs — summon Roody and ask "what's wrong here?"

📷 Sees your screen

Ask about a diagram, a rendered UI, or an error dialog and Roody looks at a screenshot of the actual screen.

🌏 Answers in your language

English, తెలుగు Telugu, हिन्दी Hindi, தமிழ் Tamil and more.

🛡 Privacy first — by architecture, not promise

  • Loads nothing until you click. Roody only appears when you summon it.
  • Refuses personal pages. Banking, payments, email, chats, social media, government sites — Roody won't run there, even if you ask.
  • Screenshots only on send. Roody captures your screen only for a message you send, never in the background.
  • Read-only, always. Roody never edits, clicks, or types on any page.
