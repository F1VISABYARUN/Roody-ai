🤝 Sharing Roody

If you give Roody to a friend: share the extension folder (or ZIP) — do NOT share your API keys. Each person should paste their own keys above.

Why? An API key is like a credit card — anyone holding it can spend on it until you revoke it. If a key ever leaks (or you stop trusting someone you shared one with), go to your provider's console and regenerate it — that instantly cuts off anyone using the old one:
  • Anthropic key → console.anthropic.com
  • Gemini key → aistudio.google.com/apikey

Want to control who uses Roody? That needs a small backend server (Roody talks to your server, your server holds the keys, you can revoke any user). Not in v1 — tell us when you're ready to share publicly and we'll add it.

🔒 Your keys & privacy

Keys are saved in chrome.storage.local on this computer only — not synced, not sent anywhere except to the matching provider (Anthropic / Google) when Roody talks to it. Use the ✕ button next to any key to wipe it. Roody only ever reads the page — it never edits.
